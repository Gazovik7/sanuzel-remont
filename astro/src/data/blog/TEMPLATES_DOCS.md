# Документация: Система шаблонов для вставок в статьях

## Обзор

Новая система шаблонов позволяет легко добавлять разнообразные элементы в статьи блога с помощью специальных шорткодов. Система поддерживает как предопределенные вставки, так и динамические шаблоны с параметрами.

## Типы шорткодов

### 1. Статические вставки (predefined templates)

Для часто используемых элементов:

```
[!INSERT key="calculatorCtaDefault"]
[!INSERT key="engineerTipDefault"]
[!INSERT key="warningBitumenMastic"]
```

### 2. Динамические шаблоны (parameterized templates)

Для кастомизируемых элементов:

#### Цитата
```
[!TEMPLATE key="quote" author="Имя автора" style="highlight"]
Текст цитаты
[/!TEMPLATE]
```

#### Сравнительный блок
```
[!TEMPLATE key="comparison" title="Заголовок"]
**Опция 1:** Описание
**Опция 2:** Описание
[/!TEMPLATE]
```

#### Раздел статьи
```
[!TEMPLATE key="section" title="Заголовок раздела"]
Содержимое раздела
[/!TEMPLATE]
```

#### Информационный блок
```
[!TEMPLATE key="callout" variant="tip" title="Заголовок"]
Содержимое блока
[/!TEMPLATE]
```

#### Предупреждение
```
[!TEMPLATE key="callout" variant="warning" title="Внимание"]
Содержимое предупреждения
[/!TEMPLATE]
```

#### Калькулятор CTA
```
[!TEMPLATE key="calculatorCta" title="Заголовок" description="Описание" buttonText="Текст кнопки"]
```

#### Чек-лист (checklist)
```
[!TEMPLATE key="checklist" title="Чек-лист подготовки"]
- [ ] Удаление старого покрытия
- [ ] Выравнивание стен
- [ ] Установка гидроизоляции
- [ ] Подготовка инструментов
[/!TEMPLATE]
```

Также доступен короткий алиас:
```
[!CHECKLIST title="Чек-лист подготовки"]
- Пункт 1
- Пункт 2
[/!CHECKLIST]
```

## Безопасность

Все пользовательские параметры автоматически экранируются для предотвращения XSS-атак. При вводе данных не нужно экранировать HTML-символы вручную.

## Пример полной статьи

```html
<h1>Пример статьи с шаблонами</h1>

<p>Введение к статье...</p>

[!INSERT key="engineerTipDefault"]

[!TEMPLATE key="quote" author="Эксперт" style="highlight"]
Ценное мнение эксперта
[/!TEMPLATE]

[!TEMPLATE key="section" title="Основные положения"]
<p>Содержимое раздела...</p>
[/!TEMPLATE]

[!TEMPLATE key="comparison" title="Сравнение вариантов"]
**Вариант А:** Преимущества и недостатки
**Вариант Б:** Преимущества и недостатки
[/!TEMPLATE]

[!TEMPLATE key="callout" variant="tip" title="Полезный совет"]
Полезная информация
[/!TEMPLATE]

<p>Заключение...</p>

[!TEMPLATE key="calculatorCta" title="Хотите узнать больше?" description="Получите консультацию эксперта" buttonText="Заказать звонок"]
```

## Обратная совместимость

Существующие шорткоды продолжают работать:
- `[!CTA_CALCULATOR title="..." description="..." buttonText="..."]`
- `[!CALLOUT variant="..." title="..."]...[/!CALLOUT]`
- `[!INSERT key="..."]`
- `[!CTA_OFF]`

## Добавление новых шаблонов

Для добавления новых шаблонов:

1. Добавьте тип шаблона в `astro/src/data/blog/templates/types.ts`
2. Создайте функцию рендеринга в `astro/src/data/blog/templates/config.ts`
3. Зарегистрируйте функцию в `TEMPLATE_RENDERERS`
4. Обновите эту документацию

## Технические детали

- Все шаблоны реализованы как TypeScript-функции
- Используется строгое экранирование HTML-символов
- Поддержка вложенных HTML-тегов в содержимом шорткодов
- Обработка атрибутов с одинарными и двойными кавычками
