# Блог-компоненты

Коллекция компонентов для структурирования контента в статьях блога. Все компоненты адаптивны и используют стили проекта.

## Доступные компоненты

### 1. ProsCons.astro
Компонент для отображения преимуществ и недостатков.

**Props:**
- `pros?: string[]` - список преимуществ
- `cons?: string[]` - список недостатков
- `title?: string` - заголовок (по умолчанию "Преимущества и недостатки")

### 2. ExpertTip.astro
Компонент для отображения совета эксперта.

**Props:**
- `tip: string` - текст совета
- `title?: string` - заголовок (по умолчанию "Экспертная рекомендация")
- `expertName?: string` - имя эксперта (по умолчанию "Эксперт")
- `expertTitle?: string` - должность эксперта (по умолчанию "Профессионал в области")

### 3. ScoreRating.astro
Компонент для отображения оценки по балльной системе.

**Props:**
- `score?: number` - одиночная оценка
- `ratings?: { criterion: string; score: number; max?: number }[]` - массив оценок по критериям
- `maxScore?: number` - максимальная оценка (по умолчанию 10)
- `label?: string` - заголовок (по умолчанию "Оценка")
- `description?: string` - описание
- `average?: number` - средняя оценка

### 4. FinalVerdict.astro
Компонент для отображения финального вердикта.

**Props:**
- `verdict: string` - вердикт
- `title?: string` - заголовок (по умолчанию "Финальный вердикт")
- `recommendation?: string` - рекомендация

### 5. RankingList.astro
Компонент для отображения рейтинга.

**Props:**
- `items: { rank: number; title: string; description?: string }[]` - элементы рейтинга
- `title?: string` - заголовок (по умолчанию "Рейтинг")

### 6. FAQ.astro
Компонент для часто задаваемых вопросов.

**Props:**
- `items: { question: string; answer: string }[]` - вопросы и ответы
- `title?: string` - заголовок (по умолчанию "Часто задаваемые вопросы")
- `addSchemaMarkup?: boolean` - добавлять ли JSON-LD разметку (по умолчанию true)

### 7. ExpertQA.astro
Компонент для вопроса и ответа эксперта.

**Props:**
- `question: string` - вопрос
- `answer: string` - ответ
- `expertName?: string` - имя эксперта (по умолчанию "Эксперт")
- `expertTitle?: string` - должность эксперта (по умолчанию "Профессионал в области")
- `title?: string` - заголовок (по умолчанию "Вопрос эксперту")

### 8. CtaCalc.astro
Компонент призыва к действию с калькулятором.

**Props:**
- `title: string` - заголовок
- `subtitle?: string` - подзаголовок (по умолчанию "Рассчитайте стоимость ремонта вашей ванной комнаты")
- `buttonText?: string` - текст кнопки (по умолчанию "Рассчитать стоимость")
- `buttonLink?: string` - ссылка кнопки (по умолчанию "/calculator")

### 9. CtaAfterRead.astro
Компонент призыва к действию после прочтения.

**Props:**
- `title: string` - заголовок
- `subtitle?: string` - подзаголовок (по умолчанию "Готовы начать ремонт ванной комнаты?")
- `buttonText?: string` - текст кнопки (по умолчанию "Получить консультацию")
- `buttonLink?: string` - ссылка кнопки (по умолчанию "/contacts")

### 10. Checklist.astro
Компонент чек-листа.

**Props:**
- `items: { id?: string; label: string; checked?: boolean }[]` - элементы чек-листа
- `title?: string` - заголовок (по умолчанию "Чек-лист")

**Примечание:** Чек-лист также можно вставлять в обычные Markdown-статьи с помощью шорткода:

```
[!TEMPLATE key="checklist" title="Чек-лист"] ... [/!TEMPLATE]
```

или короткого алиаса:

```
[!CHECKLIST title="Чек-лист"] ... [/!CHECKLIST]
```
