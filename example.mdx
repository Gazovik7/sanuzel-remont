# Пример использования блог-компонентов

В этой статье представлены примеры использования всех 10 созданных блог-компонентов. Каждый компонент демонстрирует свои возможности с различными параметрами и вариантами использования.

## Checklist

Компонент Checklist используется для создания интерактивных чек-листов:

<Checklist
  title="Чек-лист подготовительных работ"
  items={[
    { id: "1", label: "Отключить воду", checked: true },
    { id: "2", label: "Снять старую плитку", checked: false },
    { id: "3", label: "Очистить стены", checked: false },
    { id: "4", label: "Подготовить инструменты", checked: true }
  ]}
/>

## Shortcode checklist

Компонент Checklist также доступен через шорткод/шаблон; в обычных `.md` статьях можно вставлять следующее:

```
[!TEMPLATE key="checklist" title="Чек-лист подготовки"]
- Заключить договор
- Получить доступ к объекту
- Подготовить строительные материалы
[/!TEMPLATE]
```

Короткий алиас:

```
[!CHECKLIST title="Чек-лист подготовки"]
- Заключить договор
- Подготовить материалы
[/!CHECKLIST]
```

## CtaAfterRead

Компонент CtaAfterRead призывает читателя к действию после прочтения статьи:

<CtaAfterRead
  title="Хотите провести ремонт без хлопот?"
  description="Закажите консультацию специалиста и получите смету на ремонт ванной комнаты бесплатно"
  buttonText="Получить расчет стоимости"
  buttonLink="/contact"
/>

## CtaCalc

Компонент CtaCalc предлагает читателю воспользоваться калькулятором:

<CtaCalc
  title="Рассчитайте стоимость ремонта"
  description="Используйте наш калькулятор, чтобы получить предварительную оценку стоимости ремонта вашей ванной комнаты"
  buttonText="Перейти к калькулятору"
  buttonLink="/calculator"
/>

## ExpertQA

Компонент ExpertQA представляет собой вопрос и ответ от эксперта:

<ExpertQA
  question="Как выбрать плитку для ванной комнаты?"

  expertName="Иван Петров"
  expertTitle="Главный дизайнер интерьеров"
/>

## FAQ

Компонент FAQ содержит часто задаваемые вопросы:

<FAQ
  items={[
    {
      question: "Сколько времени занимает ремонт ванной комнаты?",
      answer: "Сроки ремонта зависят от объема работ и составляют от 3 до 6 недель для стандартного ремонта ванной комнаты площадью 4-6 м²."
    },
    {
      question: "Нужно ли согласование при перепланировке ванной комнаты?",
      answer: "Да, перепланировка ванной комнаты требует согласования в БТИ, особенно если затрагиваются несущие стены или изменяется расположение сантехники."
    },
    {
      question: "Какой гарантии предоставляете на работы?",
      answer: "Мы предоставляем гарантию на все виды работ сроком от 1 года до 5 лет в зависимости от типа ремонта и используемых материалов."
    }
  ]}
/>

  title="Окончательный вердикт"
  verdict="После анализа различных вариантов ремонта ванной комнаты, мы рекомендуем выбирать комплексный подход, включающий замену всех коммуникаций, качественную гидроизоляцию и современные материалы. Это обеспечит долговечность и комфорт на многие годы."

/>

## ProsCons

Компонент ProsCons показывает преимущества и недостатки:

<ProsCons
  title="Сравнение типов ремонта"
  pros={[
    "Косметический ремонт: быстрое выполнение",
    "Косметический ремонт: относительно низкая стоимость",
    "Косметический ремонт: минимальные хлопоты"
  ]}
  cons={[
    "Косметический ремонт: не решает основные проблемы",
    "Косметический ремонт: необходимость повторного ремонта через 3-5 лет",
    "Косметический ремонт: ограниченные изменения в планировке"
  ]}
/>
