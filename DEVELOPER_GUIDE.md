
# Инструкция по разработке и созданию страниц (Smirnov Marketing)

Этот проект использует **data-driven** архитектуру на базе Astro и React. Страницы услуг генерируются динамически на основе конфигурационных файлов в формате `.ts`.

## 1. Структура данных
Все данные страниц должны соответствовать интерфейсу `ServicePageData` из файла `astro/src/types/index.ts`.

### Ключевые поля конфигурации:
- `slug`: (string) Уникальный URL страницы (без слешей).
- `template`: Определяет набор и порядок блоков:
    - `'seo'`: Полный набор (Колесо баланса, Воронка, Сравнение, Калькулятор).
    - `'ads'`: Оптимизировано для Рекламы и GEO (убраны специфические SEO-блоки).
    - `'dev'`: Оптимизировано для Разработки сайтов.
- `caseIds`: (string[]) Массив ID кейсов из `CASES_DATA` (см. `constants.ts`). Если пуст, выводятся первые 7 кейсов.
- `methodology.factors`: (optional) Если массив заполнен, в Hero-секции отобразится **Колесо Баланса**. Если отсутствует — отобразится **слайдер кейсов**.

## 2. Создание новой страницы услуги

### Шаг 1: Создание файла контента
Создайте файл в `astro/src/data/services/pages/[name].ts`. 
**Пример минимального экспорта:**
```typescript
import type { ServicePageData } from '../../../types';
export const servicePage: ServicePageData = {
  slug: 'new-service',
  template: 'seo',
  // ... остальные поля согласно интерфейсу
};
```

### Шаг 2: Регистрация в роутинге
Откройте `astro/src/pages/[slug].astro`.
1. Импортируйте созданный файл: 
   `import { servicePage as newPageData } from '../data/services/pages/[name]';`
2. Добавьте импортированную переменную в массив `allPages` внутри функции `getStaticPaths()`.

## 3. Правила работы с компонентами (Critical!)

### Гидратация (Hydration)
Все интерактивные React-компоненты в папке `landing` и `islands` **ОБЯЗАНЫ** начинаться с директивы `'use client';`. Без этого страница упадет в "белый экран" при загрузке в браузере.

### Иконки
Используйте библиотеку **Lucide React**. В конфигурационных файлах иконки передаются как строки с названием компонента (например, `'Search'`, `'Zap'`, `'ShieldCheck'`).

### Хлебные крошки (Breadcrumbs)
На главной странице крошки скрыты автоматически. На внутренних страницах они передаются в компонент `Hero` через пропс `breadcrumbs`. Редактируйте их в `.ts` файле страницы.

## 4. Оптимизация PageSpeed
- Все изображения должны быть в формате **.webp**.
- Новые изображения в папке `work` или `awards` должны быть оптимизированы (рекомендуемая ширина 800-1200px).
- Для критических изображений в Hero-секции используйте атрибут `fetchpriority="high"`.
