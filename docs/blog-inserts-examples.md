### 7. Вставка списка проверок (checklist)
```
[!TEMPLATE key="checklist" title="Чек-лист подготовки"]
- [ ] Удаление старого покрытия
- [ ] Выравнивание стен
- [ ] Установка гидроизоляции
- [ ] Подготовка инструментов
[/!TEMPLATE]
```

Также доступен короткий алиас:
```
[!CHECKLIST title="Чек-лист подготовки"]
- Удаление старого покрытия
- Выравнивание стен
- Подготовка инструментов
[/!CHECKLIST]
```

В MDX можно использовать компонент:

```mdx
<Checklist title="Чек-лист подготовки">
  <ul>
    <li>Удаление старого покрытия</li>
    <li>Выравнивание стен</li>
    <li>Подготовка инструментов</li>
  </ul>
</Checklist>
```


Эти примеры показывают гибкость и мощь новой системы шаблонов вставок, позволяющей легко создавать разнообразный контент для статей блога.
