# Руководство по адаптации шаблона под новый проект

Этот проект спроектирован как гибкая база (Core) для быстрого запуска сайтов услуг. Основная логика: **отделение контента от верстки**. Вы меняете данные в одном месте — сайт обновляется везде.

---

## 1. Брендинг и Визуальный стиль

Все глобальные стили настраиваются через дизайн-систему Tailwind.

- **Цвета и шрифты**: Откройте `astro/tailwind.config.mjs`. Измените значения в секции `colors` (особенно `primary` и `secondary`) и `fontFamily`. Это мгновенно изменит тему всего сайта.
- **Логотип и Favicon**: Замените файлы в `astro/public/img/logo.png` и `astro/public/favicon.ico`.
- **Фоновые элементы**: Если в секциях используется декоративный текст или градиенты, их можно подправить в соответствующих компонентах в `src/components/landing/`.

---

## 2. Настройка глобальных данных (Source of Truth)

Чтобы не менять телефон или адрес на каждой странице, используйте файл:
`astro/src/components/landing/constants.ts`

**Что там нужно обновить в первую очередь:**
- `NAV_ITEMS`: структура меню (названия и ссылки).
- `CONTACTS`: телефоны, почты, ссылки на соцсети.
- `REVIEWS`, `CASES_DATA`, `TEAM_MEMBERS`: глобальные списки, которые отображаются на главной и внутренних страницах.

---

## 3. SEO и Микроразметка

Глобальная информация для поисковиков (JSON-LD) находится в:
`astro/src/layouts/BaseLayout.astro`

**Найдите блок `schemaGraph` и обновите:**
- Название организации (`Organization`).
- Данные LocalBusiness (адрес, часы работы).
- ID счетчиков аналитики (Яндекс.Метрика, Google Analytics).

---

## 4. Управление контентом страниц

### Динамические страницы услуг
Шаблон использует **SSG-генератор** для страниц услуг. Вам не нужно создавать новые `.astro` файлы для каждой услуги.
1. Зайдите в `astro/src/data/services/pages/`.
2. Создайте новый `.ts` файл по образцу существующих.
3. Укажите уникальный `slug` — он станет частью URL (например, `/services/my-new-service/`).
4. Все блоки (Hero, Тарифы, FAQ) рендерятся автоматически в стиле проекта.

### Статические страницы
Основные разделы (О нас, Контакты, Блог) находятся в `astro/src/pages/`. 
Они являются "обертками" для React-компонентов из папок `islands` или `landing`. Если нужно изменить структуру страницы, редактируйте соответствующий `.tsx` файл.

---

## 5. Формы и Интеграции

- **Логика форм**: Компонент `UniversalForm.tsx` обрабатывает все заявки. 
- **Куда приходят лиды**: Настройка отправки (например, в Telegram или на Email) обычно настраивается в API-обработчике или через внешние сервисы. В шаблоне предусмотрено поле `source` для аналитики источника лида.

---

## 6. Полезные команды (CLI)

Выполняйте их в директории `astro/`:

- `npm run dev` — запуск режима разработки.
- `npm run build` — генерация статического сайта (папка `dist/`).
- `npm run check` — проверка проекта на ошибки в типах и путях.
- `npm run deploy` — автоматическая загрузка на ваш FTP-сервер (требует настроенного `.env.deploy`).
- `npm run optimize:images` — автоматическое сжатие всех картинок в `public/img`.

---

## 💡 Рекомендация по работе с ИИ
При создании нового контента просто копируйте структуру любого `.ts` файла из `data/services/pages` и просите ИИ: 
*"Используя эту структуру, напиши контент для страницы [Название услуги] в стиле [Нужный тон], сохранив все ключи объекта"*.
